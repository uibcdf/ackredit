# User Guide

This section explains how to use Ackredit in your own scientific libraries.

For provisional development support for precise, opt-in third-party calls, see
the [dependency-free function provider guide](function_providers.md).

If you would rather see it working than read about it, {ref}`User_ExampleLibraries` runs
two small host libraries that ship with the repository and shows the same code producing
two different bibliographies.
